Clés VAPID — Family-app

Ce générateur crée une paire de clés VAPID directement dans ce navigateur avec Web Crypto. Il ne contacte aucun serveur et n’envoie aucune donnée.

Génère les clés une seule fois. Conserve la clé privée dans les secrets Supabase uniquement. Ne la publie jamais dans GitHub et ne la partage pas.
En attente de génération.

Format : clés Base64URL sans remplissage (=), compatible avec Web Push. La clé privée est affichée uniquement pour te permettre de l’ajouter manuellement aux secrets Supabase.
